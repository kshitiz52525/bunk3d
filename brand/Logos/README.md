# Logos

All logos are outlined SVGs with their colours baked in (`<img>` can’t recolour them). Choose by ground. Clear space is the height of the 3, and the wordmark is at least 96px wide on screen.

- `bunk3d-wordmark-dark-bg.svg` — ink-white letters, `lime` 3. Use on `bg` dark.
- `bunk3d-wordmark-light-bg.svg` — `ink` letters, ink 3 on a tilted `lime` chip. Use on light `bg` and paper.
- `bunk3d-wordmark-lime-bg.svg` — all `ink`. Use on `lime` fills.
- `bunk3d-wordmark-white.svg` — all white, for one-colour jobs on dark.
- `bunk3d-wordmark-black.svg` — all black, for one-colour jobs on light.
- `bunk3d-app-icon.svg` — `lime` 3 with `violet` offset on ink, 1024px, radius 232. The default icon and avatar.
- `bunk3d-app-icon-lime.svg` — ink 3 on `lime`, for dark surroundings.
